# Priya Couture - E-Commerce Backend (Node.js & Supabase)

Enterprise-grade Node.js / Express backend architected according to the **Life Claim Project (`Life-Broker-Node18-04-26 1`)** design pattern, integrated with **Supabase PostgreSQL Database**, **Stored Procedures / Functions (`sp_userlogindetails_get`, `sp_userlogindetails_trans`)**, and **JWT Authentication**.

---

## 🗄️ Database Table & Stored Procedures

### Table: `tbl_userlogindetails`

| Column | Type | Description |
| :--- | :--- | :--- |
| `user_sk` | `BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` | Identity / Primary Key |
| `username` | `VARCHAR(200) NOT NULL` | Login Username |
| `passwordenc` | `VARCHAR(300) NULL` | Salted bcrypt password hash |
| `password` | `VARCHAR(200) NULL` | Raw password (if provided) |
| `mobileno` | `VARCHAR(15) NULL` | Contact mobile number |
| `isactive` | `BOOLEAN NOT NULL DEFAULT TRUE` | Active account status flag |
| `createdby` | `VARCHAR(200) NULL` | Created by user/system |
| `createddate` | `TIMESTAMPTZ NOT NULL DEFAULT NOW()` | Record creation timestamp |
| `modifieddate` | `TIMESTAMPTZ NULL` | Last update timestamp |
| `modifiedby` | `VARCHAR(200) NULL` | Last updated by |

### Stored Functions in Supabase:
1. **`sp_userlogindetails_get(p_user_sk, p_username, p_userby, p_mode)`**:
   - `GetAll`: Fetches all user login records.
   - `GetbyId`: Fetches a single user record by `user_sk`.
   - `SearchUser`: Searches users by `username` (ILIKE search).
2. **`sp_userlogindetails_trans(p_user_sk, p_username, p_passwordenc, p_password, p_mobileno, p_isactive, p_userby, p_mode)`**:
   - `INSERT`: Inserts new user login record and returns `User_SK`.
   - `UPDATE`: Updates username, password, mobileno, isactive, modifiedby.
   - `DELETE`: Deletes user by `user_sk`.
   - `GETALL` / `GETBYID`: Query modes.

### 1. Database Setup in Supabase

2. Go to **SQL Editor**.
3. Copy and run the entire script in [supabase_schema.sql](file:///d:/Own_Future/2026/Priya-Couture/Priya_EcommerceBC_Node/supabase_schema.sql).

## 📡 API Endpoints & CRUD Operations

### 1. Register User (Public)
**`POST /api/auth/register`**
```json
{
  "Username": "DivyaSharma",
  "Password": "MySecretPassword123",
  "MobileNo": "9876543210",
  "UserBy": "Admin"
}
```

**Response (201 Created):**
```json
{
  "code": 1,
  "status": "Success",
  "data": {
    "model": {
      "user": {
        "User_SK": 2,
        "Username": "DivyaSharma",
        "MobileNo": "9876543210",
        "IsActive": true
      },
      "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "tokenType": "Bearer",
      "expiresIn": "24h"

  }
}
```

### 3. Get All Users (Protected - JWT)
Calls `sp_userlogindetails_get` with mode `'GetAll'`

**`GET /api/priya/ecommerce/users/list`**
**Header:** `Authorization: Bearer <your_jwt_accessToken>`

**Response:**
```json
{
  "code": 1,
  "status": "Success",
  "data": {
    "model": [
      {
        "user_sk": 1,
        "username": "PriyaAdmin",
        "mobileno": "9876543210",
        "isactive": true,
        "createdby": "System",
        "createddate": "2026-10-30T10:00:00Z"
      }
    ]
  }
}
```
